# Meridian Auctions 🏛️

Meridian Auctions is a curated online auction marketplace for distinctive art, furniture, watches, collectibles, fashion, and electronics. This repository is where I’m building the app: a polished auction experience for discovering lots, comparing current bids, and exploring item details.

## What I’m building

The current app is a front-end prototype featuring:

- 🖼️ A curated selection of auction lots, organized by category
- 🔎 Search and price sorting to help browse listings
- ⏳ Auction cards with current bids, bid counts, and time remaining
- 💷 Lot detail pages with item information and a basic bid interaction
- 📱 Responsive layouts for desktop and smaller screens

The auction data and bid interaction are currently demo-only; this project does not yet include a backend or live bidding.

## How I’m building it 🤖

This app is a project I’m building specifically with **Codex/ChatGPT** and **custom skills** that support **agentic workflows**. I use these tools to help plan, implement, review, and improve the app in focused steps while keeping the project’s direction and decisions in my hands.

## Tech stack 🧰

- React
- TypeScript
- Vite
- CSS

## Run locally 🚀

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

To create a production build or check TypeScript:

```bash
npm run build
npm run typecheck
```
